What is a CLI?

CLI stands for Command Line Interface. Instead of clicking buttons in a window, you type instructions as text. The computer responds line by line.

BROWSER (GUI) — A PRODUCT

  • You use what the company built
  • They decide what you can do and see
  • Your data lives on their servers
  • Context resets with every new chat
  • Copy-paste is your only bridge to your files

TERMINAL (CLI) — A TOOL

  • You run the software on your machine
  • No limits except your imagination and the tool's capability
  • Your files stay on your computer
  • The AI reads your actual project, not a summary you typed
  • You can chain tools: read, edit, run, test in one session
A browser is a product. A CLI is a tool. One serves you what someone else built. The other lets you build.
— Cambio Labs, AI Literacy Track
🔍

Why use a CLI for AI?

THE CONTEXT ADVANTAGE

When you use AI in a browser, you paste a question and maybe a file. The AI only sees what you give it in that text box.

When you use AI in a terminal, the AI sees your actual project. Your file structure. Your code. Your folder of notes. Your data exports. It reads everything you let it see.

IT SEES YOUR ACTUAL FILES

No more copy-paste. No more "imagine I have a file that does X." The AI just reads the file. It works with what is really there, not what you remembered to paste.

IT KEEPS WORKING WITH YOU

In a browser, each chat is a bubble. In a terminal, the session holds context across the whole conversation. You can ask follow-ups, make changes, run code, and the AI remembers what came before.

IT IS REPRODUCIBLE

Every command you run is text. You can save it, share it, re-run it. No "click the button in the top right then the dropdown then..." Just text that says exactly what happened.

IT WORKS OFFLINE

CLI tools can run local models. No internet required. No server deciding to change the UI or remove a feature. The tool is yours.

FUN COMMANDS Make the terminal smile

Pick one of these to run after the basic hello world:

figlet
$ figlet -f slant "Hello"
cowsay
$ cowsay "Hello, world!"
toilet
$ toilet --gay "Hello"
lolcat
$ echo "Hello" | lolcat
sl
$ sl
fortune
$ fortune | cowsay
If a command is missing, use the cheat-sheet install commands, or switch to the cloud terminal. Ctrl+C stops most running terminal programs.
The goal is not to memorize these. The goal is to get comfortable seeing text come alive.

FUN FIRST The classic first command

Before we do anything serious — the terminal is not all work. Try this:

$ echo "Hello, world!"
Hello, world!
That is the classic first command. It prints text to the screen. It does nothing useful. That is the point.
If you want to make it personal:
$ echo "Hello, world! My name is [YOUR NAME]."
This is the first thing you should do in a terminal: run something useless that feels cool. It breaks the fear of the blank screen.

WINDOWS WSL — Linux inside Windows

If you are on Windows, you get the best terminal experience through WSL — Windows Subsystem for Linux. It runs a real Linux environment inside Windows, no dual booting.

Install WSL (one time, 5 minutes):
$ wsl --install
Run that in PowerShell or Command Prompt as Administrator. It installs a full Ubuntu terminal on your machine.
After install:
  • Restart your computer
  • Open "Ubuntu" from the Start Menu
  • Create a username and password (for the Linux environment)
  • You now have a terminal that works exactly like macOS or Linux
Your Windows files are at /mnt/c/Users/you inside WSL. You can access everything, but it is faster to keep your project files inside the Linux filesystem (your home folder).
