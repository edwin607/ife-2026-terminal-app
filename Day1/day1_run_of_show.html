Day 1 Run of Show

Goal

Get every student into Journey, open a terminal, run a fun Hello World command, and submit a reflection.

90-minute plan

Time Minutes Segment Notes
0:00 5 Welcome & agenda Explain the day is about first contact with the terminal
0:05 10 Journey login walkthrough Show login, dashboard, where to submit
0:15 5 Terminal-readiness check Ask who already sees a terminal
0:20 15 WSL mini-lab for Windows Help Windows students only
0:35 5 Transition Verify every pod has a working shell
0:40 20 Core terminal fun Run Hello World, fun commands, personalized greeting
1:00 10 Share-out Let students show favorite output
1:10 5 Exit line Submit Journey reflection
1:15 — Air buffer / Q&A Catch stragglers

TA notes

  • One TA handles Journey login issues.
  • One TA handles terminal / WSL issues.
  • One TA floats and keeps the room moving.
  • If a pod is stuck for more than 3–4 minutes, switch them to the fallback terminal.
  • The goal is not mastery — it is first contact with the terminal.

Student deliverable

Each student submits a screenshot or copy-paste of the final line:

Hello, world! My name is [YOUR NAME].
