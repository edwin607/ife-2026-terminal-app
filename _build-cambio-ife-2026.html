How to read this
The AI track is a companion layer, not a second curriculum

The core youth social-entrepreneurship program runs on the Journey platform (checkpoints CP1–CP8). These 14 AI modules ride alongside it: each one is the applied AI lab for an existing Journey lesson. The block cards below show the run of show for each module — every block opens with a 2-minute recall, builds a real artifact, and closes on a human judgment the machine cannot make.
